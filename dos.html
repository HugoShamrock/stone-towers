— original DOS version —

The original STONET.EXE compiled in 1995, running in the browser via DOSBox-X / js-dos (WebAssembly). Includes the intro and outro FLI animations, original Sound Blaster FM music, and all 129 VGA scenes — exactly as it ran on MS-DOS.

Stone Towers — 1995 MS-DOS
click to load (~3 MB)
Controls (original DOS):
Mouse — navigate menus and interact with scenes
Arrow keys — movement in some screens
ESC — back / exit menu
F1–F10 — game functions (inventory, spells, etc.)

Tip: click the canvas to capture mouse input

Runs via js-dos (DOSBox compiled to WebAssembly). Sound may not work in all browsers. For best results use Chrome or Firefox on desktop.
